# AMVerge Scoop Bucket

Official [Scoop](https://scoop.sh) bucket for [AMVerge](https://github.com/AMVerge-team/AMVerge) on Windows.

## Install

```powershell
scoop bucket add amverge https://github.com/AMVerge-team/scoop-bucket
scoop install amverge
```

## Update

```powershell
scoop update amverge
```

## Uninstall

```powershell
scoop uninstall amverge
```
